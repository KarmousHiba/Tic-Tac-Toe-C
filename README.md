\# Tic Tac Toe Game



\## Description

A simple Tic Tac Toe game developed in C.



\## Features

\- Two players: X and O

\- 3x3 game board

\- Winner detection

\- Draw detection

\- Score management

\- Replay option



\## Technologies

\- C Programming Language

\- Embarcadero Dev-C++

\- Windows 11



\## Project Structure

\- src: Source code

\- docs: Project documentation

\- capture d'ecran: Game screenshots



\## How to Run

1\. Open src/main.c with Dev-C++.

2\. Compile the program.

3\. Run the game.
