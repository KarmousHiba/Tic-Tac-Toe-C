\# 🎮 Tic Tac Toe Game in C



\## 📌 About the Project



Tic Tac Toe is a simple two-player console game developed using the C programming language. Players take turns placing their symbols (X and O) on a 3×3 grid. The objective is to align three symbols horizontally, vertically, or diagonally.



\## ✨ Features



\- Two-player mode (X and O).

\- Interactive 3×3 game board.

\- Turn management.

\- Winner detection.

\- Draw detection.

\- Score tracking.

\- Option to replay the game.
